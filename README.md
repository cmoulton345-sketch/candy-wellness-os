## What This Is

An AI operating system built on a **comprehensive fleet of specialized agents** that work together to transform complexity into action. Each agent has a distinct role, from strategic understanding and copywriting to automated workflow execution and safety compliance.

## The Agent Fleet

The system categorizes personas into four functional groups:

1. **Core Strategic Chain**: Clarity, Atlas, Navigator, Brunsen, and Chairman Consolidated.
2. **Specialized Experts**: Collect, Consistency, Crypto, Earl, Jarvis, Psyche, Sentry, Skeptical Researcher, and Socrates.
3. **Builders & Synthesizers**: Stephen, Nate, and Web Builder.
4. **System Architecture**: Information Architect and Fileclerk.

*(For full details on each persona's role, please refer to [mission.md](./mission.md))*

## The Fileclerk Agent

The memory layer that makes everything work. An MCP server providing:

- **Institutional Memory** — Never forget decisions, constraints, or insights
- **Provenance Tracking** — Know who said what, via which AI, when
- **Multi-Party Collaboration** — Founder and clients share context with proper attribution
- **Context Compilation** — Auto-generate working summaries for efficient AI reasoning

### Architecture Highlights

- W3C PROV-O aligned schema for proper attribution
- Human-readable markdown with YAML frontmatter
- Two-layer system: Total Recall Archive + Active Context
- Persona analytics for agent performance tracking
