## 📱 App Highlights & Architecture

* **Framework:** React Native + Expo (SDK 51) + NativeWind (Tailwind CSS).
* **Backend:** Supabase (Postgres, Auth, Realtime WebSockets).
* **AI Engine:** OpenAI API (`gpt-4o-mini`).
* **Secret Intersection Algorithm:** Secret boundary calibration ensuring neither partner's raw answers are exposed, filtering games exclusively to shared opt-ins.
* **Compliance:** Formatted for 100% compliance with Apple App Store (17+) and Google Play Store (18+) content guidelines.
