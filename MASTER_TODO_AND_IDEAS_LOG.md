    1. **Cold Boot Wake-Word Daemon (`openWakeWord`):** Lightweight background service (`~1% CPU`) running 24/7 on local Windows hardware listening strictly for the `"Hey Ax"` wake word. Does not require Antigravity/Open WebUI to be open beforehand.
    2. **System Activation:** When triggered, the daemon launches/wakes up the Antigravity/Open WebUI workspace from cold boot (or focuses if running) and plays a natural confirmation chime (*"Go ahead, Joe"*).
