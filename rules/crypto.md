## 📊 Technical Analysis Framework

### Multi-Timeframe Analysis Protocol

Always analyze from higher timeframe to lower. The higher timeframe sets the bias; the lower timeframe finds the entry.

| Timeframe | Purpose | Weight |

|-----------|---------|--------|

| **Weekly (1W)** | Macro trend direction, major S/R zones | Highest — defines bias |

| **Daily (1D)** | Intermediate structure, pattern formation | High — confirms or denies weekly bias |

| **4-Hour (4H)** | Trade setup identification, entry zone refinement | Medium — operational timeframe |

| **1-Hour (1H)** | Precise entry/exit timing, trigger confirmation | Lower — execution timeframe |

| **15-Min (15M)** | Scalp entries, micro-structure only | Lowest — noise increases rapidly |

> **Rule:** Never trade against the weekly trend unless the daily shows clear structural reversal with volume confirmation.

### Core Technical Indicators

Use 2-3 complementary indicators maximum per strategy. More = noise, not signal.

| Indicator | Category | Primary Use | Key Levels |

|-----------|----------|-------------|------------|

| **RSI (14)** | Momentum | Overbought/Oversold, Divergence | >70 overbought, <30 oversold |

| **MACD (12,26,9)** | Trend/Momentum | Trend direction, crossover signals | Signal line cross, histogram divergence |

| **Bollinger Bands (20,2)** | Volatility | Mean reversion zones, squeeze breakouts | Touch outer band = potential reversal |

| **EMA 21/50/200** | Trend | Dynamic S/R, trend confirmation | Price above = bullish structure |

| **Volume** | Confirmation | Validates breakouts, identifies exhaustion | Breakout + 25%+ volume = confirmed |

| **CVD (Cumulative Volume Delta)** | Order Flow | Buyer vs seller pressure, divergences | Price up + CVD down = bearish divergence |

| **VWAP** | Value | Institutional fair value reference | Above = bullish intraday bias |

### Chart Pattern Recognition

| Pattern | Type | Reliability | Setup |

|---------|------|-------------|-------|

| **Head & Shoulders** | Reversal | High (on daily+) | Neckline break + volume = entry |

| **Double Top/Bottom** | Reversal | High | Second touch + divergence = strongest signal |

| **Bull/Bear Flag** | Continuation | High | Flag break in trend direction = entry |

| **Ascending/Descending Triangle** | Continuation | Medium-High | Flat edge break + volume = entry |

| **Wedge (Rising/Falling)** | Reversal | Medium | Narrowing range → explosive breakout |

| **Cup & Handle** | Continuation | Medium-High | Handle pullback = entry, rim = target |

| **Range/Rectangle** | Neutral | Medium | Trade the edges or wait for breakout |

> **Validation Rule:** No pattern trade without (1) volume confirmation, (2) multi-timeframe alignment, and (3) defined invalidation level.

### Candlestick Patterns (High-Reliability Only)

| Pattern | Signal | Context Required |

|---------|--------|-----------------|

| **Engulfing (Bullish/Bearish)** | Reversal | Must be at key S/R level |

| **Pin Bar / Hammer** | Rejection | Long wick must reject significant level |

| **Morning/Evening Star** | Reversal | Three-candle structure at extremes |

| **Doji** | Indecision | Only meaningful at key levels after trend |

## 🤖 Bot Strategy Framework

### Strategy Categories

| Strategy | Best Market Condition | Risk Level | Complexity |

| **Arbitrage** | Cross-exchange price gaps | Low | High |

### Bot Design Protocol

When designing any trading bot, define ALL of these parameters before writing a single line of code:

#### 1. Strategy Definition

- **Market condition fit:** When does this strategy work? When does it fail?

- **Pair selection:** Which pairs and why (liquidity depth, volatility profile)

- **Timeframe:** What candle interval drives decisions?

- **Directional bias:** Long-only, short-only, or bidirectional?

#### 2. Entry Logic

- **Primary signal:** What triggers the trade? (indicator cross, pattern break, price level)

- **Confirmation filter:** What must also be true? (volume, trend alignment, momentum)

- **Entry type:** Market order or limit? At what price/level?

#### 3. Exit Logic

- **Take-profit:** Fixed %, trailing, or indicator-based?

- **Stop-loss:** Fixed %, ATR-based, or structural (below key level)?

- **Time-based exit:** Close position after N candles if neither TP nor SL hit?

#### 4. Risk Management

- **Position size:** % of capital per trade (max 2%)

- **Max concurrent positions:** How many open at once?

- **Daily drawdown limit:** Pause bot if daily loss exceeds X%

- **Max leverage:** Conservative (3-5x recommended for beginners)

- **Kill switch:** Conditions that halt all trading immediately

#### 5. Infrastructure

- **Platform:** Hyperliquid, dYdX, etc.

- **Execution:** Python script, Hummingbot, or no-code platform

- **Monitoring:** Telegram alerts, email notifications, dashboard

- **Logging:** Every trade logged with timestamp, entry, exit, P&L, reason

3. **Revenge trading** — Losing → doubling down → losing more → doubling again → gone

## 📐 Position Sizing Calculator

For any trade, calculate position size BEFORE entering:

```

Risk Amount = Account Balance × Risk Percentage (1-2%)

Position Size = Risk Amount ÷ (Entry Price - Stop Loss Price)

Leveraged Position = Position Size × Leverage

Example ($1,000 account, 1% risk, 3x leverage):

  Risk Amount = $1,000 × 0.01 = $10

  If entry = $85,000, stop = $84,150 (1% away)

  Position Size = $10 ÷ $850 = 0.0118 BTC

  With 3x leverage: controls $30 margin → 0.0353 BTC

```

> **Never calculate position size based on "how much you want to make." Calculate it based on how much you can afford to lose.**
